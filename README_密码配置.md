# QQ Web Pro 密码配置指南

## 🎯 快速开始

### 第一步：打开配置文件

打开 `main.py`，找到配置区（约第23行）：

```python
# ================= 管理员密码配置 =================
ADMIN_PASSWORD_1 = ""  # 账户管理面板密码
ADMIN_PASSWORD_2 = ""  # 管理员日志查看密码

# ================= 服务器启动密码配置 =================
SERVER_STARTUP_PASSWORD = ""  # 服务器启动密码
```

### 第二步：设置密码

```python
# 示例配置
ADMIN_PASSWORD_1 = "admin123"
ADMIN_PASSWORD_2 = "logs456"
SERVER_STARTUP_PASSWORD = "startup789"
```

### 第三步：运行程序

```bash
python main.py
```

如果设置了启动密码，会提示输入：

```
==================================================
QQ Web Pro - Server Startup Authentication
==================================================
Enter startup password: 
```

输入密码后服务器启动。

## 📚 三种密码说明

| 密码 | 用途 | 默认值 | 配置方式 |
|------|------|--------|---------|
| 🔐 启动密码 | 启动服务器时验证 | 无（留空不需要） | 仅 main.py |
| 👤 管理密码1 | 访问账户管理面板 | 123 | main.py 或 config.json |
| 📊 管理密码2 | 查看管理员日志 | 321 | main.py 或 config.json |

## 🔑 启动密码特点

- ✅ **启动保护**: 运行程序时需要输入密码
- ✅ **密码隐藏**: 输入时不显示字符
- ✅ **尝试限制**: 最多3次尝试，失败后退出
- ✅ **仅代码配置**: 无法通过配置文件修改
- ✅ **可选功能**: 留空则不需要密码

## ❓ 常见问题

### 忘记启动密码？

打开 `main.py`，清空配置：

```python
SERVER_STARTUP_PASSWORD = ""
```

### 如何禁用启动密码？

设置为空字符串：

```python
SERVER_STARTUP_PASSWORD = ""
```

### 密码输入时看不到字符？

这是安全特性，使用 `getpass` 模块隐藏密码输入。

## 🔒 安全建议

### ✅ 推荐

- 生产环境必须设置启动密码
- 使用强密码（至少12位）
- 定期更换密码
- 记录到安全位置

### ❌ 避免

- 使用弱密码（如 123, password）
- 所有密码相同
- 将密码写在明显位置
- 从不更换密码
